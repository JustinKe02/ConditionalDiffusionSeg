## 二、学习曲线反映的问题

1. U-Net训练损失从第70轮0.245降到第100轮0.201，但val mIoU从75.79降到74.51；出现训练/验证趋势分离，提示泛化波动或过拟合倾向。只凭这条曲线不能确定原因，当前使用第70轮best是合理的。
2. UNet++在后期有波动，第100轮重新达到最高值，没有稳定停滞的证据。
3. DeepLabv3+、PSPNet、HRNet的val mIoU第90→100轮分别增加约0.69、0.93、2.27个百分点，说明预算末段仍有收益。最佳轮位于终点并不单独证明未收敛，但无法声称已经测得其最佳可达水平。
4. Mask2Former第70/80/90/100轮val mIoU为82.56/82.41/83.59/84.24%，先前短暂平台随后继续改善。第1→100轮损失64.01→8.84，不存在数值发散；十组预测的匹配损失求和使其绝对值大于一般语义损失，不能跨方法比较loss大小。
5. SegFormer-B1较早达到高质量，第60→100轮87.62→88.17%，后期收益较小；在当前有限预算下表现出较高的训练效率。该结论不等同于所有训练配方下更优。

多数方法背景和多层IoU已经很高，当前模型间的主要差距来自单层、少层及边界。不可仅由高mIoU宣称困难类别已解决。

## 三、对当前方法的判断

E3R相对SegFormer的val差值：mIoU约+0.39pp，单层+0.81pp，少层+0.10pp，前景边界F1+7.09pp。少层→单层错误率E3R为17.64%，SegFormer为14.32%，E3R反而高约3.33pp。因此主张应是“边界质量收益”，不能写成薄层混淆全面减少。

SegFormer参数13.68M，E3R18.20M；E3R四步共享权重但仍有额外串行计算。当前不宜宣称E3R更轻或更快。旧GLP与本批验证中的峰值reserved显存部分包含训练遗留缓存，不用于最终推理显存排名；采用独立test进程/干净缓存条件下的数据，口径不齐则标为待补。

现有E0/E1/E3R test mIoU为94.84/93.72/93.43%，边界F1为69.68/70.92/72.92%。测试结果已经显示区域精度与边界质量的取舍，不能仅以val略高改写成整体精度全面领先。

- 九种方法各用原val-best EMA权重在test27评估一次；保存掩码、颜色图、混淆矩阵并逐图核验。

- 由现有协调器输出comparison_summary.json与final_analysis.md；同一权重的两个采样种子不是两次训练重复。
