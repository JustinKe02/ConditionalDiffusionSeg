# 当前具体优化方向（按用户要求取消多训练种子）

日期：2026-10-18；proposal_only；automatic_execution=false。
用户明确不需要多种子实验。后续统一训练seed42，取消此前seed123/2026和6次完整方法重复安排；历史计划保留为历史记录。采样3407/3408仅为同权重推理复核，不是多训练种子。本次仅修改计划，无代码实现或训练。

## 1. 第一优先：将参照改成独立、可关闭的修正分支

现状：reference_data.py把RGB与q*C/q拼接；condition_model.py的image_input一次卷积同时编码七通道。F1共享参数经过参照训练，即使某图q=0，也不会自动复现F0。拒绝组mIoU从77.70降至76.03%，但这只是现象，尚不能唯一归因于共享训练。

具体改动：

- opt-in新模型以现有F0 best为基础，基础模型始终只接收RGB＋四个零辅助通道，冻结参数。
- 新分支读取基础解码特征h0、RGB、参照C、xt和时间t；两层32通道3×3卷积＋零初始化四通道1×1输出，时间嵌入投影相加。保持单头。
- 输出 y=f0+q*R；q=0时直接返回f0，覆盖每个DDIM步骤与recycling教师调用。原图级q在所有滑窗一致。
- 新数据路径须显式定义C和q，避免将旧q*C再次误乘而无意改变置信度幂次；首批参考估计器、接受阈值与缓存保持不变。
- 先验证零初始化等价、冻结参数不变、拒绝组整图数值等价与恢复，再训练。要取得的收益是接受组改善且拒绝组保持原预测；不保证全局mIoU必然提高。

先做两次匹配训练：A同容量分支但C置零；B输入真实C。二者共享q、基础权重、初始化、噪声、裁块顺序。每次新阶段40轮；累计基础40＋适配40轮。若B不能超过A，不能把收益归给参照。

## 2. 第二优先：噪声阶段与状态决定参照修正强度

现状：普通融合使用h=0.5*(h+evidence)，不随时间改变。已有adaptive代码支持时间/状态门控，但还未训练；它不是上述冻结参照分支，且不保证q=0回到F0。

具体候选是在方向1有效后，仅改变参照残差门控：

    g = q * sigmoid(Conv1x1(concat(h0, E_reference(C))) + Linear(time_embedding(t)))
    y = f0 + g * R

门控为逐位置单通道，广播到四个类别；基础模型继续冻结。与方向1的固定g=q比较，保留原修正分支和其他训练设置；记录新增参数，不将比较解释为完全排除门控容量的纯时间效应。若要主张时间项作用，需另做同结构去掉时间输入的对照。

高噪声阶段更多依赖RGB/参照、后期减少不必要修改只是待检验假设，不强行写死为结论。预先固定低/高噪声区间，记录门控值、实际修正幅值和最终性能；避免门控长期饱和或接近零。拒绝组依然硬关闭。

阶段性仅在方向1通过后追加这一组，门控无收益则保留简单版本。优先不同时更改噪声采样比例、recycling比例或引入注意力大模块。

## 3. 第三优先：单层/少层训练覆盖，而非盲目提高单层权重

F0的few→mono约22.36%；单层precision约67.28%、recall约85.79%。因此应同时关注把少层错当单层的假阳性，以及把单层错当背景的漏检，不能只追求更高单层召回。

具体裁块候选：每张训练图仍产生一个512裁块，概率50%普通随机、25%围绕单层像素、25%围绕少层像素；缺目标类时回退普通随机。目标像素只来自训练标签，随机选像素并抖动裁块位置，确保选中像素在框内。训练图数、更新数、增强与损失不变，记录每类像素占比、缺类回退率和边界覆盖。

先只比较普通/类别裁块，不再同时增加类别权重、focal或边界损失。裁块若用于最终方案，Direct也需要同预算同裁块对照，排除通用数据策略贡献；这项本身不作为算法原创点。

损失优化暂列诊断：当前L=0.5*CE+0.5*foregroundDice+1.0*MSE。先在固定训练批次按低/高噪声、GT/recycled状态记录损失对同一输出/可训练分支的梯度范数和方向，再决定是否值得单独比较MSE系数1.0→0.5。系数0.5只是待登记单点候选，不是已经证实的最优值；不能仅依据各loss数值大小判断梯度冲突，不重启已失败的双头方案。
