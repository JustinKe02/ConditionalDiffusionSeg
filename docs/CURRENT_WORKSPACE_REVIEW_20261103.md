## 2. 当前主模型的真实计算逻辑

### 2.1 数据组织

[GLPDataset](/root/autodl-tmp/ConditionalDiffusionSeg/work/glpflow_core.py:115)沿用120/25/27张固定划分。四类分别为背景、单层、少层和多层。训练每图每轮抽取2个512×512裁块；50%的抽样机会尝试以薄层像素为中心，其余随机裁块，并使用整图一致的光度变化、旋转和翻转。

120张训练图对应每轮240次裁块曝光，批量8形成30次更新，100轮为3000次更新和24000次端点监督曝光。这里的24000不是独立图像数量。训练划分内部存在m169与m56解码RGB重复、标签相差929像素的历史记录，图像内容实际独立性也不能由ID不重叠推出。

全局缩略图由图像裁齐到64倍数后缩小4倍。原图2560×1922在全局分支中对应2560×1920，再得到640×480缩略图；局部原尺寸预测仍覆盖1922行。靠近截断边缘的先验采用边界填充采样，应在方法中说明这两种尺寸的区别。

评价数据集会生成用于监督/统计的标签派生字段，但实际predict接口只接收RGB、缩略图和图像ID，未把真实标签传入R/I/N/F预测器。不能因数据对象包含mask就判定标签泄漏，应检查具体调用链。

### 2.2 条件与网络

[GLPFlowNet](/root/autodl-tmp/ConditionalDiffusionSeg/work/glpflow_core.py:353)包含局部RGB编码、全局图像编码、状态分支、两层三流联合注意力和解码器。四组受控版本共用18,197,460个参数。

局部特征通道为32/64/128/192；全局token为20×15个、每个256维。状态输入为4通道x、1通道归一化熵U、4通道先验P、4通道上一预测自条件，共13通道。全局token与局部图像特征可从端点损失获得梯度；作为条件输入的P、U分离梯度，先验头另由先验损失监督。

初态为 `x0 = 2P − 1 + αUε`。R/I使用α=1，N/F使用α=0。取消初态噪声不等于取消熵输入，更不等于删除全局先验或减小网络。

网络没有独立边界输出头，也没有显式边界损失。边界改善是实验观察结果，不能仅由“细化”或“注意力”模块名称预先保证。

### 2.3 轨迹训练与损失

[受控train_step](/root/autodl-tmp/ConditionalDiffusionSeg/work/chapter_controlled_20261031/core.py:35)为每个样本随机选取k∈{0,1,2,3}，先无梯度运行前k次预测，再监督选定端点。不是所有步骤同时反传，也不是完整链的反向传播；每批8个样本都保留一次有梯度端点监督。

损失为 `0.5 CE + 0.5 foreground Dice + 0.5 prior_loss`。prior_loss内部为0.5软标签CE与0.5前景Dice；后者使用软标签argmax目标。当前主方法没有速度场MSE。因此论文现用的“端点参数化的流式状态更新与轨迹监督”比直接宣称原始CFM目标更准确。

模型生成训练状态的思想与既有扩散分割循环训练存在关联，不能仅凭该概念证明首创。可对照[循环训练原始论文](https://arxiv.org/abs/2308.16355)与[Flow Matching原始论文](https://arxiv.org/abs/2210.02747)界定区别；本轮未进行新的全面原创性检索。

### 2.4 四个对照真正改变了什么

| 版本 | 被监督位置的状态 | 初态噪声 | 状态反馈 |
|---|---|---|---|
| R | 自身轨迹 | 有 | 时间加权Euler形式 |
| I | 标签端点与初态的插值 | 有 | 时间加权Euler形式 |
| N | 自身轨迹 | 无 | 时间加权Euler形式 |
| F | 自身轨迹 | 无 | 直接端点反馈 |

I仍执行自己的无标签预测前缀，以产生自条件；只在选定监督位置替换x。I推理时不使用标签。这使R−I比历史E3−R更接近单因素设计。

R/I/N采用 `x_next = x + Δt/(1−t) × (2q−1−x)`，四个更新权重依次为1/4、1/3、1/2和1。F采用 `x_next = 2q−1`，时间输入和自条件仍保留。N/F虽然噪声系数为0，代码仍消耗同样的噪声随机数，以维持后续随机序列。

历史E3→R不只是状态变化：监督时间、自条件、Shortcut、直接监督样本数和层级覆盖均不同。E3每批6个样本接受直接端点监督、2个走Shortcut，R全部8个接受端点监督；历史约20个百分点BF提升不能全部归因于状态来源。最新整合稿已经披露这一点；旧源码文件头的“Only the training state changes”仍是过度简化的历史说明。

### 2.5 推理路径与成本

[受控predict](/root/autodl-tmp/ConditionalDiffusionSeg/work/chapter_controlled_20261031/core.py:104)在整图上生成一次随机场，使窗口重叠处共享对应噪声；全局条件每图计算一次，局部RGB特征每窗口批次计算一次，多步复用。512窗口、384步幅共35窗，重叠位置平均概率，最后取argmax。

固定K=4、level=1下返回第1/2/4次端点，是同一模型同一轨迹的提前返回。它不等同于重新设置K=1/K=2，更不等同于独立训练的一步/两步网络。

推理目前大量使用CPU概率累积，每个窗口批次将概率传回CPU。原尺寸累计概率张量约75 MiB，另有噪声场和计数张量；CPU/GPU传输和窗口拼接具有实际成本。整图计时从已经加载的样本进入predict开始，不包括样本磁盘读取及此前的标准化，也不等于显微镜系统端到端时延。

优先考虑融合注意力实现、减少不必要展开、窗口/坐标缓存和传输融合，并在新实验版本核验输出及确定性。图像特征已经跨步缓存，再增加同样的缓存不是新优化。 可评估PyTorch SDPA作为候选实现，但其不同后端可能产生浮点差异，不能预设逐位一致或保证加速；应在本项目实际PyTorch 2.5.1、数据类型和确定性设置下核验。[PyTorch官方说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention)

GLP推理路径假设图像足够大且窗口配置满足网络下采样要求，没有早期通用predict_image中完整的小图padding流程；受控infer_windows还明确限定返回位置为1/2/4。这对当前2560×1922固定数据成立，但若用于任意尺寸显微图，需增加输入尺寸校验、padding及输出裁回。当前GPU/FP32计时也不能直接代表CPU或边缘运行时。

### 4.5 历史代码与当前方法不能混读

早期GaussianDiffusion单头路径同时用输出承担分类与x0回归，并在采样终点返回截断到[−1,1]的分数；GLP则使用softmax端点概率和不同状态更新。两条路径的目标和输出约束不同。旧扩散路径性能不佳不能直接证明当前轨迹训练无效，也不能把旧recycling、dual-head或边界损失配置写进R的实际算法。
