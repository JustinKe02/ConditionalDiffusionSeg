## 1. 实验定位与研究问题

任务固定为像素级层数类别分割：输入二维材料RGB光学图像，输出背景、单层、少层、多层四类别掩膜。初期使用主MoS₂数据集；其他材料与外部MoS₂留作后续适用范围验证，不混入首轮训练。

第3章研究“条件扩散的逐步预测能否改善困难类别与边界”；第4章研究现有RepELA-Net的轻量化；第5章部署第4章最终模型。本项目不以RepELA的粗分割为必需输入，不修改PhysicalNet现有模型或实验结果。

三个问题分别用实验回答：

1. 条件扩散与同规模的直接分割相比，分割质量、波动和计算开销怎样？
2. 若出现收益，能否排除只是增加迭代计算的作用？
3. 类别平衡与边界约束是否有额外收益，是否损害其他类别或推理效率？

不预设扩散一定更准确，不把普通去噪网络或简单循环细化直接称作扩散。首次实现采用简化、可核查的方法，不同时堆叠预训练大模型、文本条件、图像合成、蒸馏等因素。

## 2. 文献基础与首版技术路线

参考：

- [SegDiff: Image Segmentation with Diffusion Probabilistic Models](https://arxiv.org/abs/2112.00390)：以图像为条件进行扩散式分割。
- [Denoising Diffusion Implicit Models](https://arxiv.org/abs/2010.02502)：用于较少步数的采样及步数—效果比较。

本项目首版是针对四类别材料分割的独立适配，不宣称严格复现上述论文。复现论文与提出改进属于不同任务；若后续要报告“复现结果”，需另行对齐原作者架构、目标、训练和采样设置。

### 2.1 首选：连续高斯扩散作用于四通道类别表示

将掩膜y转换为四通道one-hot，并缩放为 `x0 = 2*one_hot(y)-1`。这里只对类别向量加噪，不把0/1/2/3作为连续厚度做回归，也不把它们解释成等间隔物理层数。

训练采样时间步t和高斯噪声epsilon，构造：

\[
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon.
\]

网络接收原图I、带噪掩膜xt与时间步t，预测干净类别表示 `x0_hat=f_theta(I,xt,t)`。采用x0预测参数化是首版设计选择，不与epsilon预测、v预测或离散类别扩散混写。离散扩散可作为后续替代路线，本轮不同时开发两套。

推理只输入原图和初始高斯噪声，从高噪声时间步逐步恢复类别表示，最终按四通道得分argmax得到类别图。真实mask仅用于训练监督或评估计算，绝不用于初始化验证/测试的采样。

### 2.2 网络首版

- 轻量U-Net风格骨干，基础通道32，通道倍率1/2/4/8，GroupNorm、SiLU与跳跃连接；先不加全局注意力。
- 最简单的图像条件为RGB与四通道xt拼接，形成7通道输入。
- 时间步采用正弦嵌入与MLP，注入残差块；具体层数、分组数与参数量在实现后写入架构配置。
- 输出四通道连续得分，作为x0估计；语义辅助损失使用同一得分的softmax，采样器的clipping约定单独固定并记录。
- 所有比较网络尽量使用相同宽度、层数和归一化；输入通道差异导致的小幅参数差异实际测量，不宣称完全等参。

### 2.3 训练目标候选

首版拟采用 `L = L_x0_MSE + 0.5*L_CE + 0.5*L_Dice_fg`。

其中MSE对连续类别表示进行去噪监督；CE覆盖四类别；Dice只对三个前景类别取平均。系数是预实验起点，不是已验证的最优值。直接/非扩散迭代基线使用同样的语义损失 `0.5*CE+0.5*Dice_fg`；扩散额外去噪目标是方法的一部分，不能把差异只归为网络结构。

训练时每个样本随机选一个t，做一次网络前向/反向；不需要每个训练batch执行1000次去噪。采样步数主要影响验证和推理开销。

类别平衡扩展仅改变CE权重，拟用训练集频率的逆平方根，归一化后限制极端值；具体归一化/截断值在正式协议冻结前确定，并对基线设置对应控制。边界扩展使用GT类别边界带上的额外CE，拟定3×3形态边界、权重0.1；只在训练时使用GT边界，不把GT边界输入推理模型。该项是边界加权监督，不宣称已经实现了新边界网络。

## 4. 分阶段实验矩阵

### P0：数据与数学流程检查，不形成论文性能结论

1. 数据完整性、类别映射、split哈希、裁剪对齐和归一化检查。
2. one-hot编码/解码、扰动均值方差、t边界、x0预测与采样公式的一致性检查。
3. 用已知x0构造oracle去噪检查采样器，防止时间步索引、系数和终止条件错误。
4. 普通/迭代/扩散模型分别进行前向、反向、有限梯度、保存重载、实际显存检查。
5. 测试真实mask未进入验证/测试采样路径；固定噪声seed时输出应可复核。
6. 选训练集中2—4张图的固定裁块（覆盖四类）做过拟合检查，观察损失和各类预测是否能学到；不能用test做这一步，也不设“必须100%mIoU”的不合理通过标准。

建议debug尺寸256、batch2，仅作功能检查；真实512和batch2也必须冒烟通过。过拟合检查使用固定图块及可控训练噪声，并另测独立噪声下的采样效果；训练去噪损失低不等于自由采样已成功。

### P1：三组可行性实验，先少量投入

| ID | 方法 | 目的 | 初始预算 |
|---|---|---|---|
| P1-DIRECT | 直接四类别U-Net | 建立可靠分割与资源基线 | seed42，40轮 |
| P1-ITER | 非扩散共享权重迭代网络 | 排除多次计算本身的作用 | seed42，40轮，5次迭代 |
| P1-DIFF | 图像条件扩散分割 | 检查扩散训练、采样及分割潜力 | seed42，40轮，20步DDIM评估 |

P1全部采用相同训练数据、512裁块、batch2和优化设置。迭代模型以固定均匀四类概率图起步，输入原图和当前概率，预测下一步得分；不用高斯扰动或扩散转移公式。初始计划最终步监督，若增加中间监督需单独记录。实际训练/推理次数与用时逐组报告，不能说三组完全等计算量。

仅使用train/val比较，不跑test来选方向。40轮是流程与趋势预实验，不足以据此断言扩散无效或已经优于基线；出现有诊断价值的趋势可按预定更长预算扩展。P1权重不续训混入正式200轮比较，正式从相同协议的随机初始化重跑。

### P3：推理设置研究，优先复用现有权重

- DDIM步数：5/10/20/50，同checkpoint、相同初始噪声条件比较。
- 重复采样：1/2/4次，统一平均类别概率后argmax，记录累计NFE和延迟。
- 初始噪声稳定性：固定checkpoint，对若干预定采样seed评估，分别报告模型训练seed与采样seed的波动。
- 条件敏感性：图像条件移除/打乱可作诊断，但推理时打乱属于输入扰动，不等同于从头训练无条件对照。若主张条件模块贡献，需要真正训练的消融。
- 输出错误与边界分析：成功、典型、失败案例使用固定样本，保留原始类别PNG。

只用val选择正式采样设置并冻结；最终test不能按样本挑最好seed或最好采样结果。多次采样分歧只先称预测波动，未经验证不称可靠不确定性或真实多解分布。

## 6. 评估协议与扩散特有注意点

### 6.1 所有模型固定滑窗

在原分辨率图像上统一使用512窗口、384步长；边缘覆盖、padding、概率融合相同。不使用“显存够就整图、不够才滑窗”的自动协议切换。与PhysicalNet历史结果的直接排名必须等旧模型按同协议重评估后再进行。

对扩散模型，以图像ID与预设sampling seed生成整张图的四通道初始噪声场，各窗口读取对应区域，以减少重叠窗口随机噪声不一致。该措施不保证消除拼接差异，仍需检查接缝；采用其他噪声组织方式时单独记录。窗口输出类别概率先融合，再argmax，不能平均整数类别ID。

25张val、每图约35窗口、20步采样，约需17,500次窗口级去噪调用/次验证（单次采样）。重复采样会继续成倍增加。若批量执行多个窗口，墙钟时间可改变，但总NFE仍需如实统计。

### 6.2 指标

- 主指标：汇总全测试集混淆矩阵计算的四类mIoU，包含背景。
- 类别指标：单层、少层、多层IoU，以及前景mIoU和每类F1。
- 边界指标：选定一种明确实现的Boundary F1或Boundary IoU，固定容差并给出敏感性；不能将边界平滑直接等同边界更准。
- 资源：参数、训练峰值显存、采样步数、总NFE、512图块延迟、整图端到端延迟。
- 稳定性：3训练seed均值±样本标准差；采样seed差异另报。

保存每图整数混淆矩阵和全局矩阵。逐图缺失类别规则明确；主mIoU不是逐图mIoU平均。附加样品级bootstrap时以独立样品为单位，不把所有像素当独立样本。

### 6.3 不允许的评价方式

不使用GT或GT扰动作为test初始掩膜；不按GT挑多次采样中的最好一次；不只展示有利类别；不只报单步去噪速度而忽略完整采样；不把新模型单种子与旧模型最好seed直接排名。

## 7. 服务器顺序与成本预算

当前检查：单张RTX3090 24GiB，检查时空闲；项目父目录所在盘约39GB可用。默认单训练进程顺序运行。

执行顺序：P0数据/数学检查 → 训练裁块过拟合 → 三组512冒烟 → P1三个40轮预实验 → 验证集分析与协议冻结 → E01—E03九次 → 必要时E04—E06及匹配控制 → P3采样设置验证 → 最终test与论文图表。

不能用前一章常规网络的“每轮时间”直接估算扩散工期。先测：训练step时间、20步窗口采样时间、整套val时间和I/O开销。

估算公式：`T_run ≈ epochs*T_train_epoch + N_val*T_full_val + T_save_and_eval`。

120训练图、batch2对应每轮60个batch；200轮约12000次训练batch。每10轮验证一次约20次，扩散20步设置约350,000次窗口级去噪调用用于整个训练过程的验证。具体墙钟时间必须实测，不承诺几小时或几天。

若验证开销过大，可统一改为更低频率或固定的验证图块协议用于开发，但正式比较仍需同样选模规则，并记录与整图val的区别；不能只给扩散更少或更有利的验证样本而不披露。

磁盘仅保存best/last、配置、日志、数值指标及必要PNG。不保存每轮完整采样轨迹或全数据四通道float概率。任何自动清理规则实现前需明确保留策略，不删除现有PhysicalNet文件。

## 8. 后续代码实现顺序与验收

以下模块的首版已实现，实际文件采用data.py/model.py/diffusion.py/trainer.py等组织，详见README；研究验收仍需逐项完成：

1. `datasets`：数据引用、split快照、同步增强、固定seed、标签校验。

4. `engine`：训练/验证、固定滑窗、噪声管理、完整checkpoint和恢复。
5. `metrics`：混淆矩阵、每类指标、边界指标和资源计时。
6. `scripts`：先debug和预实验入口，再正式矩阵队列；默认不自动连跑全部实验。

必须验证：训练可学习；没有mask条件泄漏；随机性可复核；滑窗覆盖完整；重载前后输出一致；恢复包含optimizer/scheduler/RNG；sample参数与训练参数化一致；输出范围和argmax类别正确。

阶段通过与否依据技术正确性、验证集效果及计算成本共同判断。若扩散不优于普通或迭代模型，应分析并记录，不自动扩展到全部18次，也不为了得到优势改测试口径。若效果只在某类或边界成立，可在明确资源代价下讨论该范围。
