## 1. 当前决定与新问题

原F1整体筛选失败；后续冻结F0参照残差B相对F0只提高0.0571/0.0491pp，相对同容量无参照内容A只有0.0035/0.0081pp。停止当前参照估计＋输出残差方向，不自动追加门控、解冻、延长轮数或改变失败门槛。保留全部权重、缓存、失败结果。

下一步检验：现有图像条件是否语义表达不足？将主要语义提取放在RGB编码器，分割状态通过独立分支修正后，扩散能否在相同RGB条件下超过直接分割及确定性多步修正？这是新假设，不是既有失败的唯一原因。

本章仍以单层/少层识别与分割质量的算法问题为主；缓存、批处理及少步采样是计算成本控制，不能替代精度和机制证据，也不将第3章改成第4章的轻量部署研究。

## 2. 建议结构：强RGB语义编码＋状态修正

    RGB → 一次语义编码 E(I) → 多尺度语义特征
                                  ↓
    分割状态 s、时间/迭代步 t → 状态编码 → 多尺度融合 → 共享解码器 → 四类输出

- RGB编码器建议4级32/64/128/256通道，每级两个残差块，GroupNorm/SiLU，无外部预训练。不同于原F0只由输入卷积和逐级下采样构成的轻量图像路径。
- 状态分支建议4通道输入，4级16/32/64/128通道，逐级下采样、注入时间嵌入；1×1无偏置投影到对应RGB通道，以加法融合。宽度及确切块数在实现检查后、效果评估前冻结，不做隐性架构搜索。
- 解码器使用多尺度跳跃连接、上采样和残差块，输出四类；保留高分辨率路径以保护薄层与边界。首批单头，不同时增加注意力、类别裁块、新损失或物理参照。
- 整个新网络从零训练，RGB编码器与状态/解码模块共同学习；不沿用冻结F0输出的适配方式，不继承额外基础40轮预算。
- 在同一图块的多步推理中只计算一次RGB特征；与s/t相关的状态编码和解码仍每步计算。首次仅优化静态RGB特征复用，不声称整个U-Net可以缓存。
- RGB静态特征的作用是提供更强条件；是否提高质量必须由下面新对照证明。旧F0图像卷积只占约4%运算，单缓存旧分支不等于完成这次结构设计。

图像/分割双编码器融合已有[SegDiff](https://arxiv.org/abs/2112.00390)先例；状态自适应条件已有[MedSegDiff](https://proceedings.mlr.press/v227/wu24a.html)先例；回灌已有[Fu等](https://arxiv.org/abs/2303.06040)研究。上述新结构首先是研究平台与对照，不直接命名为已成立的原创算法。

## 3. 在效果训练前先选择batch并完成实现检查

用户取消多训练种子，所有新训练固定seed42。此前batch2/4只测试过合成单步，不能当作最佳吞吐结论；本次必须先补真实稳态测试。

先做一次训练集上的失败诊断，不追加优化步：固定若干接受参照的训练裁块，对已有B比较真实C、置零C和预定置换C时的修正幅值/输出敏感性，并检查CE、Dice、MSE对分支的梯度范数和方向。它用于区分输入几乎未被使用、分支表达受限、目标约束等可能性，不用训练裁块分数替代验证失败，也不预先认定某一项就是原因。若发现实现错误先解决并独立登记，不带着错误进入新结构；否则记录诊断再开展新假设。

1. 对三个候选模式分别测试训练batch2/4/8/16（显存允许且吞吐仍增长时再考虑更大偶数值）。每项先预热10步，再计时30步，包含真实数据加载/增强、损失、反向、AdamW及适用的recycling教师调用。隔离进程处理OOM，保留失败记录；计入allocated/reserved、每秒样本数与每次更新秒数。
2. 取三组均可稳定运行、综合吞吐合适的共同训练batch；尽量保留至少约10%总显存余量供波动，若平台/实测需要更多则用更多。若各组速度最优点不同，优先新实验间可比性，公布吞吐表与选择理由，而非宣称一个batch对所有模型速度都最优。
3. 比较验证窗口batch1/4/8/16，保留每张图的原全图噪声场、窗口顺序和融合规则。记录数值误差/预测变化，选定后新三组统一评估协议；不承诺批量与逐块逐位一致。
4. 分解GPU前向/采样、数据读取、CPU↔GPU复制、融合和边界指标耗时。此前约31.9秒/图是含指标的A验证时间，不是新模型纯推理延迟，也不含首次参照拟合。
5. 验证梯度、缓存与不缓存的功能一致性、DDIM状态更新和独立噪声、完整断点恢复及旧权重兼容。新源/配置先备份，冻结新批次；不绕过旧哈希守卫。

吞吐测试为工程诊断，不把其训练损失或训练裁块成绩当作验证效果。测速后的权重全部与新效果实验隔离，正式pilot重新初始化。此处选的是吞吐合适的batch，不保证它是分割精度最优batch。

S0不执行状态路径，共享RGB/解码部分的初始权重需与S1/S2一致；报告实际可训练/有效参数差异，不用未执行的占位参数伪装同容量。S1/S2状态结构和初始化一致，更新时间步语义、训练状态与目标差异明确登记。

上表是三个必需比较模式，最多三次新训练。若最终S0在架构执行、初始化、选定batch、数据/优化/选模协议上经审计与历史Direct完全等价，可复用历史Direct，减少为两次新训练；不因名称相似直接复用，也不为机械凑三组重跑已等价的结果。

S1建议用四类均匀概率的编码2p−1（每类−0.5）初始化，之后由2softmax(y)−1更新状态；使用与五步采样位置一致的预定阶段嵌入。不加高斯扰动、不执行DDIM；反传经过五次修正，RGB编码仅计算一次。

S2从独立高斯状态开始；T1000/cosine/x0预测，沿用已验证的高噪声50%、recycling50%训练配方与0.5CE+0.5前景Dice+1.0MSE。S0/S1为0.5CE+0.5前景Dice。这些任务目标不同，不能按总loss数值排名。S1五步反传与S2单次随机t加教师的训练计算量也不同，报告实测训练时间。

所有新组seed42、512裁块、FP32、共同选定batch、同train120与增强、每图每轮一个裁块、40轮、原AdamW/lr2e-4→1e-6/warmup5/cosine、相同验证频率。三组每轮曝光相同，更新次数按共同batch重新登记；不能继续无条件写2400。若batch>2，与历史batch2的40轮结果仅作背景参考，不能将差异全部归于新结构。

主选择协议在训练前固定：每10轮全25图验证，以各自固定推理设置的全局四类mIoU选best。S2首批主设置固定5步、单采样3407；3408只评估同best。S0确定性无需重复不同采样seed，S1无高斯噪声也无需伪重复。各组报告每类IoU、单层precision/recall、少层→单层、单层→背景、前景边界F1、单图时延、MAC/参数与显存。

S2样本级NFE为35窗口×5步=175/图；窗口batch会降低批调用次数，不改变样本级NFE。S0为35、S1为175。初次效果阶段不再自动追加20步/多采样网格。S2若需20步质量上限，只在阶段报告后独立登记、评价同一个五步选定best，不用20步重选来挽救原筛选。

## 5. 建议主筛选规则与停止条件

以下是建议探索性门槛，需执行前冻结，不是统计显著性标准，不保证最终原创性：

- S2较S0全25图mIoU至少+0.50个百分点。
- S2较S1全25图mIoU至少+0.30个百分点，以检验扩散相对确定性修正的额外收益。
- S2相对S0的单层/少层平均IoU至少+0.50个百分点，单个类别和前景边界F1各自下降不超过0.50个百分点；同时报告全部类别，不能仅挑最好子组。
- S2同best的3408相对S0/S1仍为正向；仅为推理噪声复核，不当作训练种子重复。
- 若只有速度提高而没有上述质量证据，不作为第3章算法创新筛选通过。旧Direct/Iterative/HR原40轮分数用于背景，但正式优势判断优先采用本次同RGB主干、同batch的新对照。

三组完整运行，不根据中途排名换指标或选另一个预算。若S2未达到预定质量门槛，先分析新对照和训练诊断，不自动接200轮、不恢复参照叠加、不追加门控；若仅确定性修正有效，承认尚无扩散独立优势，并重新评估第3章路线。

## 6. 通过后才研究具体创新模块
