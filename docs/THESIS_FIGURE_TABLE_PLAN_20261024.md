## 二、第3章写作方向

### 1. 主张：边界质量显著提升，区域精度与最强基线相当

- 边界 F1 稳定领先。test 前景边界 F1：E3R 72.92，SegFormer-B1 66.36，Mask2Former 66.30，E0 69.68。少层边界 F1 差距最大：E3R 68.8 vs SegFormer 58.0（+10.8pp）。val 上同样是 E3R 最高（74.09 vs SegFormer 67.00）。
- 区域精度只能说相当。test mIoU：E3R 93.43，SegFormer 94.41，E0 94.84（全场最高）。按整图逐张比，E3R 在 23/27 张图上优于 SegFormer，中位高 0.90pp；全局差距集中在 m122（逐张剔除测算 −0.86pp）和 m150（−0.47pp）。

### 2. 标题和贡献按证据强弱重新排序

- 采样对齐训练是最强、最一致的证据。E3→E3R 在 val/test 上 mIoU +1.60/+1.44pp，边界 F1 +20.0/+20.1pp；机制证据完整（状态差异诊断、四步链逐步细化）。
- 全局分支的证据不一致。E1−E0：val +3.06pp，test −1.12pp。适合作为网络结构介绍，不宜作为独立的精度贡献。
- 先验引导初态没有独立收益（E3≈E2，12胜13负），不列为贡献。

建议：

- 标题：基于采样对齐条件流匹配的二维材料层数精细分割（"全局—局部"写进方法小节名）。
- 贡献三点：
  1. 全局—局部条件端点预测网络；
  2. 采样对齐训练，缓解训练状态和推理状态不一致；
  3. 在统一协议下与 9 种从头训练的方法对比，并从边界距离、逐图、步数—成本等角度分析。

### 3. 正文中必须如实写明的事项（只写数值，不做失败案例图）

- E0 的 test mIoU 最高；E3R 比 E0 低 1.41pp，但边界 F1 高 3.24pp。
- E3→E3R 同时改了状态来源、时间网格、自条件，并关掉了 Shortcut，只能称"方案整体有效"。
- 统一预算下，7/9 个基线的最佳轮在第 100 轮，比较反映"统一有限预算下的表现"。
- 只有训练 seed 42；3407/3408 不是重复训练。test 结果已经看过，不称盲测。
- val 的少层像素约 26% 来自 m109；SegFormer/Mask2Former/E3R 的 val 少层→单层误判中 94–96% 集中在 m109 和 m31。test 的主要错误则是大面积多层图上的多层→少层（m122/m150）。val 与 test 主要错误类型不同，在表注或正文中用数值交代。

### 4. 实验节顺序

统一设置 → 对比方法（test 主表，val 作补充）→ 消融 → 采样对齐机制 → 边界分析 → 步数与成本 → 定性对比 → 小结（引出第4章的效率问题）。
