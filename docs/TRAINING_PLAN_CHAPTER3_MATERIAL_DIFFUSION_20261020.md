# 第3章下一批训练计划：材料条件类别扩散及质量—成本证据

制定日期：2026-10-20。用户要求沿第3章层数判别机制→第4章轻量化→第5章部署的思路，提出第三章后续训练计划。**本文件是计划，不是执行授权；未实现、未测速、未启动、未排队，automatic_execution=false。** 当前GPU空闲，上一批P0/P1已完成。

## 1. 这批实验必须回答什么

研究主线：基底相对光学对比度条件下的离散类别扩散修正。目标是证明材料成像证据进入类间转移后，能改善背景、单层、少层的歧义；同时量化逐步修正获得质量收益所需的推理代价。

该问题承接近期RefineCatDiff和CRAC-DM，但不把类别扩散、粗到细、类关系或置信度本身当成原创。机制与原文来源见docs/LITERATURE_DRIVEN_DIFFUSION_PLAN_20261020.md；跨章资源口径见docs/CHAPTER3_TO_4_QUALITY_EFFICIENCY_BRIDGE_20261020.md。

不再追加P0/P1映射、损失权重、高噪声比例的小矩阵，也不执行先前建议的P0/P1固定裁块诊断。旧实验只作历史证据保留。

## 2. 第一批只有四组训练

| 模式 | 方法与起点 | 要排除的解释 | 预算 |
|---|---|---|---|
| N0 | RGB、相对对比度C、可靠度r、共同初始概率P的直接分割 | 单次判别加成像证据是否已经足够 | 新增100轮、seed42 |
| N1 | 同输入、同修正容量，从P出发的确定性五步修正 | 是否只是更多计算与循环修正带来收益 | 新增100轮、seed42 |
| N2 | 以P为终端分布、固定全局类关系的类别扩散 | 通用类别扩散修正的贡献 | 新增100轮、seed42 |
| N3 | 与N2相同网络和目标，加入可靠度调节的图像/位置相关光学类关系 | 材料证据进入扩散核的独立贡献 | 新增100轮、seed42 |

N1/N2/N3匹配可学习修正容量，四组获取相同条件。N0作为直接预测基线，不声称与多步模型同计算量。N2是机制对照，不冒充完整RefineCatDiff或CRAC-DM复现。

N0与旧S0输入不同、训练预算不同；N1也改变了起点与输入，因此已有分数不能替代本批对照。每组仅训练一次，不做多训练种子。四组各回答不同问题，不是在同一方案上反复换参数。

## 3. 初始化与共同先验预算

共同先验复用已完成的Direct best，不再训练一遍先验。其推理仅由RGB生成P与基底候选，不利用val/test的GT。先验权重在新批次中固定。

四组共享RGB/兼容解码层统一从同一Direct权重初始化；新增投影、状态和时间层按seed42进行对应一致初始化。RGB路径新增输入的初始化与映射必须在实现前登记，不能声称不兼容张量也被直接复用。N1/N2/N3对应新增层逐张量一致。

每组报告为“共同继承已完成Direct40轮预算＋新增100轮”，而不是从零100轮。先验及初始化来自同一旧run，不把它们重复计为两次独立基础训练。计算完整推理资源时，固定先验也计入系统参数、存储、MACs和首次预测开销。

## 4. 统一训练与选模协议

| 项目 | 本批建议设置 |
|---|---|
| 数据 | 原MoS2 train120/val25，只读；120记录/119独立RGB的事实保持披露 |
| 裁块与增强 | 原尺度512×512，每图每轮一个裁块，同步旋转/翻转；四组相同裁块与数据顺序 |
| 训练seed | 42 |
| 新增轮数 | 每组100轮，统一完整日程，不从P0/P1的last接着训 |
| 样本曝光 | 每组12000次新裁块曝光 |
| batch | 新计算路径真实测速后统一选定；batch2=6000新更新，batch4=3000，batch8=1500 |
| AdamW | lr2e-4、min_lr1e-6、weight_decay1e-4，warmup5轮后cosine，clip1.0 |
| 数值精度 | 默认沿用FP32以减少与历史的执行差异；若调整，四组统一且重新登记 |
| 验证 | 第20/40/60/80/100轮完整25图，全局四类mIoU选best |
| 空间推理 | 512窗口、384步长，按整图一致的条件/噪声场切窗融合 |
| 训练损失 | N0/N1用0.5CE+0.5前景Dice；N2/N3用同一类别后验KL及同一CE/Dice辅助项，KL系数在实现前冻结 |
| 类别扩散 | 建议T=100，训练t在1…100均匀采样；不照搬高斯T1000/900分层/50%回灌配方 |
| 主推理工作点 | N1五次修正；N2/N3五次离散反向计算，使用其区间后验，不能沿用高斯DDIM更新式 |
| 扩散选模与复核 | 3407选五步best；3408仅复核同一best，不重选、不算第二训练seed |
| 保存与恢复 | best/last、完整优化器和RNG状态、指标/预算、冻结哈希；保留失败日志 |

不增加新的类别采样策略、边界损失、注意力模块或预训练来源来同时改变多个因素。100轮是计划预算，不能预先保证充分收敛；结束后报告曲线，不自动延长。

## 5. 实现前需要写实的核心内容

1. 基底场B与可靠度r：从RGB及共同先验背景候选估计，全图拟合后切窗。不能默认边角是背景；基底不足或饱和时降低可靠度。所有组相同，val不使用GT估计B。
2. 光学类证据：仅用train建立四类对比度统计；不假设颜色随层数单调，不声称经过物理厚度标定。
3. 类别链：用可核验的行随机Q_t，末步精确落到共同先验P；推导累计Q、跳步转移与反向后验。固定的Q条件在训练期间不随待训去噪器变化。所有类别概率保持正下限，先验错误允许被推翻。
4. N2/N3差异：固定全局关系与材料条件关系的替换；网络、辅助输入、损失、训练顺序、初始化和读出保持一致。
5. 资源边界：若先验/概率缓存，说明缓存生成成本、磁盘/RAM限制及首次处理时间；不落盘无限量全分辨率FP32轨迹。所有统计、缓存与新模型输出只能写本项目。

只对新增计算路径做必要工程验证：概率与后验合法性、真实batch资源、恢复一致性。不重跑已有工程检查或额外效果诊断小矩阵。新计算图的吞吐未知，因此暂不给小时数承诺；开训前以实际完整步骤和25图验证耗时估算总时长。

## 6. 主比较的价值标准与停止条件

以下为新批次建议标准，最终在执行前一次冻结，不改写已完成P0/P1原门槛：

- N3−N0全局四类mIoU≥1.00个百分点。
- N3−N1及N3−N2分别≥0.50个百分点。
- N3相对N0的单层/少层平均IoU≥1.00个百分点。
- 单层、少层及前景边界F1分别不下降超过0.50个百分点。
- 同best3408保持对N0/N1/N2的优势方向，不据此重选权重。

这些标准用于判断研究价值，不是多训练种子显著性证明。全部四组按冻结预算完成；如果未通过，保留结果、报告并停止此路线，不自动追加200轮、模块或新噪声表。

若N0足够好，不能把成像证据的收益改写成扩散收益；若N1不弱于N3，不能声称扩散本身必要；若N2不弱于N3，不能声称材料条件核贡献成立。

## 7. 同一批best如何形成第3章与第4章的衔接证据

主训练通过后，仅对最终N3的固定五步3407-selected best，预先固定以下采样工作点：1/3/5/10步，完整25val；五步已有结果复用，N1/N2保持主比较的五步结果，不扩展成所有模式×所有步数矩阵。这是同一权重的质量—成本分析，不再训练或以其他步数重选best。3408不扩展成所有步数的大矩阵。

所有模式记录：整体mIoU、单层/少层IoU、前景边界F1、全推理系统参数/权重大小/MACs、512窗口模型延迟、原图端到端延迟、峰值推理显存。端到端推理剥离混淆矩阵/边界指标时间，不用现有25图评估耗时冒充纯推理延迟。

第3章用这些证据说明精细类别修正的质量和多步代价；第4章以RepELA的单次前向、紧凑计算和资源取舍承接。不能预先规定RepELA必须快几倍，也不能故意给扩散只保留慢版本。RGB缓存按实际使用计入，不按步数乘整个主干参数或峰值内存。
