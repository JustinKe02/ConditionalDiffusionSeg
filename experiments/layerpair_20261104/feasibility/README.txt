范围：本次诊断仅使用原 train120。标签几何统计保留全部并单列重复敏感性；关系交叉验证删除 m169（与 m56 解码 RGB 相同）。不含原始显微图像或掩膜。

A. labels/：训练标注中可参考区域的空间上限。per_image.csv 是纯 17×17 内区定义下的逐图统计。按原尺寸、8 连通计算区域，区域对是不同组件；不能把图块或区域数解释为样品数。

B. reference_check.json / anchors_per_image.csv：固定第99轮第1980步Direct，推理只使用全图RGB缩略图，标签在选点后计算各候选的纯度。32×32原图块覆盖先验网格2×2格，阈值作用于四格中最低的该类概率。每个预测连通组件最多一块，每类最多四块。主分析阈值0.85，正确定义为该块至少90%的标注像素与候选类别一致。reference.log 列示其他阈值。模型本身训练时已见过这些图；不是独立样品准确率。reference_check.py 若用于生成完全相同的候选，须使用 JSON 记录的 SHA256 所对应的原检查点，当前训练目录的 last.pt 会随训练前进。归档的候选供固定条件下重算。

C. pair/：标注区域的区域对实验。93个图像、816个有序对（正反向非独立）。三分类预测比参考薄/同级/厚。每个关系先按图平均，再宏平均。跨图替换匹配真值参考类；区域类别不进入这个关系比较头。regions.json + compare.py 可重算该三类探针，target.py 为已知两类参考的补充二分类实验。运行评分脚本时切换到 pair 子目录。

D. joint/：模型自动参考、标注定位查询区域的单层/少层判别实验；详见目录 README。候选正确与否不作为过滤条件。使用标签定位纯净查询并排除自参考，仍非端到端实际推理；折外仅指轻量分类头，非 Direct 主干。共同支持集以外样本没有计入其成绩，不应外推至全图分割。图像分组不能替代来源独立的样品分组。

主要结果：两类纯17×17区域在90/120图共存；模型在119图选出291块，其中273块对目标类别纯度≥90%。标注定位的薄/同级/厚三分类：同图85.57%，同一头换跨图同类参考70.89%。进一步用真实自动参考、标注定位目标做单/少二分类（92图280区域）：同图89.69%，只用目标85.45%，跨图训练及测试83.58%，冻结同图头替换参考87.15%。同图与目标单独相比，按图重采样95%差值区间[-0.46,+9.22]个百分点。上述为不同任务指标，不可解释为分割 mIoU。建议仅进入小型冻结主干原型。
