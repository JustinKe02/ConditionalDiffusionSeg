Train-only model-selected reference sensitivity check (no RGB images included).
extract.py: cwd ConditionalDiffusionSeg; argv[1] directory with reference_check.json.
score.py: argv[1] directory with joint_data.json. Requires scipy and numpy.
Scores use 5-fold by image (greedy query-count balance), excluding m169 (duplicate of m56); references are selected from trained Direct in-sample predictions. No guarantee of specimen-level independence.
One query per true thin connected component with a 17x17 pure interior, sampled as the core point nearest the core centroid. Ground truth defines queries and excludes every overlapping reference in the same ground-truth component; it never filters candidates by their correctness. Use the highest-confidence eligible predicted reference per query (with >=0.85 threshold); only common support is scored.
Models: balanced logistic regression, same RGB query features, reference class and signed RGB difference where applicable. The cross model uses up to 10 different-image training-bank references matched on predicted class and confidence for each query; their probabilities are averaged for tested queries. 'swap' uses the same-image-trained model and replaces its held-out reference without retraining. 'anchor_label_control' keeps the reference predicted label but omits all reference appearance. C=1 fixed. All methods apply to tag-pure patches; not a segmenter test. Bootstrap CIs condition on fitted OOF models, sampling field IDs. Reference selector was trained on these fields and not refit per fold.
To reproduce with the supplied data: python score.py /absolute/path/to/joint
out.log: first line 'Supported 280 of 314 images 92' means 280 supported queries of 314 eligible pure-interior components, spanning 92 images. Cross model trains on 10 donors per query while same trains on one; use swap for the frozen-classifier counterfactual. 95% intervals are percentile, 5000 image resamples, in fractional units.
